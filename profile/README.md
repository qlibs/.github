## Qlibs++ - C++ libraries

> ### Mission

- #### Testability

  - `Compile-time` self-testing upon include
  - Focuses on `composability`, `declarativeness`, `ease of testing`

- #### Performance

  - Applies `compile-time` and `arch`\* driven optimizations
  - Strive for 'fast' compilation-times

- #### Simplicity

  - Single [header](https://github.com/qlibs/qlibs#faq)
  - Strive for minimal `API` and `dependencies`\*
  - Available on https://compiler-explorer.com

> Daily [releases](https://github.com/qlibs/qlibs/releases) ([gcc](https://gcc.gnu.org), [clang](https://clang.llvm.org), [msvc](https://visualstudio.microsoft.com/vs/features/cplusplus)\*)
